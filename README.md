# Quiz Application (Python)

## Project Description

The Quiz Application is a simple Python program that asks multiple-choice questions and checks the user's answers. At the end, it displays the total score.

## Features

- Multiple-choice questions
- Checks answers automatically
- Calculates the final score
- Displays the result
- Simple menu-driven interface

## Technologies Used

- Python

## How to Run

Run the program using:

python quiz_application.py
